# Кинотека — найди свою историю

Статический каталог фильмов и сериалов на HTML/CSS/JavaScript.

## Запуск

Откройте `index.html` в браузере или ссылку, где был получен сайт. Для более надежной работы в локальном режиме запустите сервер из папки проекта: `python -m http.server 8000`, затем откройте `http://localhost:8000`.

## Подключение API

Нажмите «Настройки», вставьте собственный API-ключ с https://kinopoiskapiunofficial.tech/ и нажмите «Подключить API». Сервис проверяет ключ реальным запросом. Каждый пользователь вставляет свой ключ; встроенного общего ключа нет.

Ключ хранится в `sessionStorage` (до закрытия вкладки) или при явном выборе в `localStorage` (до удаления). Запросы выполняются непосредственно в API из браузера. ВНИМАНИЕ: при использовании сайта браузер показывает ключ в запросах в devtools, а сохранённые ключи доступны JS на данном origin. Это приемлемо только если пользователи доверяют сайту и своему устройству.

Если API блокирует CORS на вашей версии браузера или домене, запросы не будут работать в полностью статическом режиме. Тогда нужен разрешённый API-провайдером прокси или серверная архитектура.

## Разделы

- Главная: подборки популярных фильмов, топ-250, краткий список «Хочу посмотреть».
- Каталог: поиск по названию и фильтры жанра, страны, года, рейтинга, типа, сортировки; постраничная загрузка.
- Фильм: описание, рейтинги, технические данные, актёры и команда, сезоны и серии, кадры (разные виды), видео, рецензии, факты, награды, финансы и прокат, похожие/связанные фильмы, источники просмотра (если предоставлены API).
- Карточки участников с биографическими сведениями и фильмографией.
- Локальные списки: хочу посмотреть, просмотрено, любимые; экспорт и импорт JSON.
- Светлая/тёмная тема, адаптивность.

## Ограничения

Сведения и доступность вкладок зависят от API. Список изображений и рецензий пока показывает только первую страницу API. Полная фильмография может быть обширной; на странице участника выводятся первые 60 записей. Функции просмотра видеофильмов / пиратский плеер отсутствуют; ссылки «Где смотреть» берутся из API, если там есть доступные площадки. Списки локальны для браузера и не синхронизируются между устройствами: перенос через экспорт/импорт JSON.

Официальная документация: https://kinopoiskapiunofficial.tech/documentation/api/

## Изменения версии 1.1
- Фотографии открываются в модальном окне с перелистыванием, клавишами ← → и Esc.
- Трейлеры воспроизводятся во встроенном HTML5-проигрывателе либо iframe разрешённого хостинга. Видео, запрещающие встраивание, остаются доступными по ссылке на источник.
- Рецензии закрыты по умолчанию, раскрываются по клику, даты отформатированы по-русски.
- Кнопка «Смотреть» строится по ID Кинопоиска: `https://kinokino.vip/film/{id}/`. Наличие файла видео на стороннем сайте не проверяется. Учитывайте права на контент и условия сторонних сайтов.
- Прямые ссылки `www.kinopoisk.ru/film/ID/` открывают карточку и очищают поле. Неподдерживаемые ссылки очищаются через 5 секунд.
- Ссылки `hd.kinopoisk.ru` используют отдельный нечисловой идентификатор: приложение пробует прочитать название из метаданных страницы и найти его через API. Чаще всего браузер не сможет прочитать HTML из-за CORS, поэтому предусмотрено ручное указание названия. Автоматическое сопоставление HD ID с обычным ID не гарантируется.
- Статус просмотра по обычной подписке / Amediateka **не определяется**: Unofficial API не отдаёт надёжное тарифное состояние, поэтому отображается честное «не проверено» со ссылкой на Кинопоиск.
- На главной показываются первые десять произведений коллекции `TOP_250_MOVIES` как «Топ-10 Кинопоиска», а также список популярных, жанровые кнопки и пример подборки по первому доступному жанру. Это не самостоятельная официальная подборка TOP_10.
- Светлая тема стала бежево-пастельной, декоративный знак заменён на стилизованную киноплёнку/бобину.

## Изменения версии 1.2
- Кнопки просмотра и Кинопоиска стоят в первой строке, три личных списка — во второй. Отметка «Просмотр на Кинопоиске: не проверено» удалена. Автоматическое определение конкретного тарифа без достоверного API и авторизации не реализовано.
- Рецензии плавно раскрываются и закрываются, тип рецензии виден всегда (цветной статус вместо стрелки).
- Нормализованы возрастные ограничения (например, `age16` → `16+`) и русские даты, включая дату синхронизации и выпуски эпизодов. Время синхронизации отображается, если передано API, в часовом поясе UTC (во избежание ложной локализации).
- В каждом разделе съёмочной команды участники с фотографиями выводятся первыми.
- При открытии карточки сайт проверяет дополнительные разделы через API и скрывает те, для которых в ответе нет данных. Это увеличивает количество API-запросов при открытии фильма. Если запрос к отдельному разделу не удался, вкладка не показывается; повторное открытие карточки повторит проверку.
- HD-ссылки оставлены в предыдущей реализации: их разрешение через браузер не гарантируется из-за CORS. Скрейпинг страниц Кинопоиска и проверка тарифов не включены.
